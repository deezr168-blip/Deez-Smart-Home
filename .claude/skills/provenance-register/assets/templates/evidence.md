# Evidence and verification register

Status words: VERIFIED, REPORTED, ASSUMED, UNKNOWN, N/A. See `references/status-vocabulary.md`.

One row per claim or item of evidence. Record that evidence exists and where it
is held; do not copy confidential statements into the register. Use initials or
an ID rather than a name for any person.
