# Equipment register

Status words: VERIFIED, REPORTED, ASSUMED, UNKNOWN, N/A. See `references/status-vocabulary.md`.

Owner, model, serial and rating are never filled in from inference. If a cell is
not backed by a VERIFIED or REPORTED row with a Source, it says UNKNOWN.
Keep the columns of an existing register as they are; add these only when starting one.
