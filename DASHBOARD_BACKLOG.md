# Dashboard Backlog

Ranked implementation queue maintained by the Entity & Feature Scout
routine. Kept selective — prefer a small number of high-value,
evidence-based opportunities over a large speculative feature list.

Each item includes:

- ID (e.g. `FEAT-001`)
- Priority: HIGH / MEDIUM / LOW (P0–P3 per `PROJECT_STATE.md`)
- Owning routine
- Affected view/area
- Verified entities involved (if applicable)
- Current problem/opportunity
- Recommended implementation
- Expected benefit
- Dependencies/blockers

Items are removed or marked closed when repository evidence shows they
have already been implemented.
