## Important: no entity IDs here, by design

The access path currently available to Claude (the Home Assistant Assist/MCP connector) reports **friendly names, domains, areas and states — but not `entity_id`s**. See `docs/access_verification.md`.

So this inventory is **name-keyed, not ID-keyed**. Treat it as a map of what exists, not as a source of entity IDs.

> **Never infer an `entity_id` from a friendly name in this file.** Friendly names are not unique here — several devices below share a name across different domains — and HA's slugification is lossy. Entity IDs must be read from the entity registry over an authenticated REST/WebSocket session before anything references them.
