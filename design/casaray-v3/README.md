# CasaRay V3 — design workspace

An interactive prototype of the next CasaRay dashboard, plus the design
documents behind it. **Design only.** Nothing here is deployed, and nothing
here changes the V2 dashboard, the legacy dashboard, the theme, the automation
package or any deployment script.

Branch: `casaray-v3-design`, cut from `ha-deploy` at `18a4e5d`.

| File | What it is |
|---|---|
| `prototype/` | The prototype: `index.html`, `styles.css`, `app.js`, `data.js` (demo data), `i18n.js` (EN / 中文), `icons.js` (Material Design Icons, the set HA uses) |
| `FEATURE_INVENTORY.md` | Everything V2 does, where it went in V3, rooms, controls, integrations, requirements |
| `DESIGN_SPEC.md` | Tokens, type, layout per breakpoint, components, bilingual rules, the path into HA |
| `ENTITY_MAPPING.md` | All 132 entity IDs the prototype uses, gaps where no entity exists, and a 25/09 live check |
| `screenshots/` | `test_results.json` from the last harness run. The 18 PNG renders are regenerated by the harness and not committed (see below). |
| `tools/` | Entity verifier, entity-table generator, test harness, icon builder |

## Open the prototype

Open `prototype/index.html` in a browser. It needs no server and no build.
Fonts load from Google Fonts and fall back to system fonts when offline.

- **Demo data pill:** every value is demonstration data, and no control
  reaches a device.
- **Demo controls** (top right): switch scenario (*Evening, two home* ·
  *Everyone away* · *Device outage*), show each card's entity IDs, language,
  theme.
- Deep links work: `index.html#security`, `index.html#room-kitchen`.

## Checks

From the repository root:

```sh
python3 design/casaray-v3/tools/verify_entities.py         # every ID exists in the 05/09 export
python3 design/casaray-v3/tools/gen_entity_table.py        # regenerate ENTITY_MAPPING.md §2c
NODE_PATH="$(npm root -g)" node design/casaray-v3/tools/test_and_capture.cjs
```

The harness needs Playwright with Chromium. It runs 68 checks and rewrites
`screenshots/`:

- **Navigation:** every board, every room, back, browser back, deep links, the phone tab bar and More sheet.
- **Responsiveness:** no horizontal scroll and no squeezed card names, on every board at 390, 820, 1180, 1366 and 1600px, in both languages. Checks for 2 columns on the wall iPad, 3 on desktop and 1 on the phone.
- **Interaction:** lights, brightness, language (via `input_boolean.chinese_dashboard`), theme, bills, AC, purifier, shopping list, One tap, entity captions, Escape.
- **Honesty:** the outage scenario says *No data*, never `0 W` or "All closed", and counts the checks that could not answer.
- **Console:** no page errors.
